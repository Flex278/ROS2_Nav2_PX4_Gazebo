# Конфигурация PX4

Сюда помещаются файлы настройки полётного контроллера:

- `airframe` — кастомный планер (SYS_AUTOSTART / airframe_id)
- `params` — файл параметров (`param load` / `param import`)
- `mixer` — микшеры выходов (опционально)

> PX4 SITL в связке с Gazebo Harmonic обычно использует встроенный airframe
> `gz_x500` (или `gz_x500_depth` для дрона с камерой глубины). Кастомные файлы
> кладутся сюда и подключаются на этапе запуска SITL.
